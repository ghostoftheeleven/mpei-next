# Настройки приложения, которые можно менять без выпуска версии

`config.json` читает Android-приложение при запуске (последний ответ хранится на устройстве, без сети берётся он). Все значения — строки.

| Ключ | Что делает |
|---|---|
| `force_update_required` | `"true"` — предложить обновиться, если `force_update_version` новее установленной |
| `force_update_version` | актуальная версия приложения |
| `force_update_min_version` | версии ниже этой показывают экран «обновитесь», который нельзя закрыть |
| `force_update_url` | куда ведёт кнопка обновления |
| `force_update_description` | короткий текст на экране обновления |
| `ft_show_flakes_effect` | `"true"` — включить снежинки (настройка «Снежинки» тоже появляется) |

Раньше эти значения хранились в Firebase Remote Config; Firebase из приложения убран. Запрос уходит на `raw.githubusercontent.com`, как и за метками карты.
